# NOTESY
## What is it ?
This is a simple note taking CLI APP made by RUST and the main objective for this is to give the Tech guys who are fond of Terminal Apps a place where they can keep their notes and browse them.

## How to make it work :
- Make sure you have <a href="">git</a> installed in your computer. If not install it via:

```bash
sudo apt install git
```

- Configure git if needed to.


- Make sure you have <a href="">RUST</a> installed on your computer.You can verify if installed via:
 ```bash
 rustup --version
 ```
If nothing shows or if it says <i>Command 'rustup' not found</i> visit <a href="">RUST's website</a> on guidelines to install it.


- Clone this project locally via :

 ```bash
 git clone https://github.com/SamDeCqa/Notes-App.git
 ```
